# El Cosmos Arquitectónico 🌌
**Aprovechando las cosmogonías jerárquicas para resolver la anomalía de la materia oscura y el Big Bang mediante dinámicas dependientes de la escala.**

Este repositorio contiene la documentación oficial, manuscritos y datos teóricos del modelo cosmológico del "Cosmos Arquitectónico". 

## 📄 Sobre el Proyecto
Este trabajo propone un modelo verificable y dependiente de la escala que desafía el paradigma estándar (ΛCDM) y su dependencia del 95% en variables inobservables (materia oscura y energía oscura). 

Aplicando una rigurosa ley de escala algorítmica donde la fuerza decae de forma inversa a la distancia (1/r) en regímenes de aceleración ultra-baja, el modelo demuestra que un macro-universo plano, rotatorio y pulsante explica de manera intrínseca:
* La estabilidad cósmica.
* Las oscilaciones de expansión-contracción (el "respiro" galáctico).
* El transporte de materia a gran escala.
